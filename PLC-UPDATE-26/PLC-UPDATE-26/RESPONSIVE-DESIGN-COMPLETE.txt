🔧 RESPONSIVE TECHNIQUES USED

1. CSS clamp() Function
   • Fluid sizing without media queries
   • Scales smoothly between min/max values
   • Example: font-size: clamp(12px, 2vw, 18px)
   • Provides smooth, not-stepped scaling

2. CSS Grid with auto-fit
   • Automatically arranges cards
   • No hardcoded column numbers
   • Adapts to container width
   • Example: grid-template-columns: repeat(auto-fit, minmax(..., 1fr))

3. CSS Flexbox
   • Flexible layouts
   • Content wrapping
   • Easy reordering
   • Natural spacing

4. Media Queries (Breakpoints)
   • 1024px: Tablet adjustment
   • 768px: Mobile layout
   • 480px: Phone optimization
   • Each refines the experience

5. Viewport-Relative Units
   • vw (viewport width percentage)
   • vh (viewport height percentage)
   • Scales with screen size
   • Always proportional
