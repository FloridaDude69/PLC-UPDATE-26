📖 COMPLETE WALKTHROUGH

STEP 1: Double-Click the Shortcut
────────────────────────────────────────────────────────────────────────────
  • Look on your desktop for "PLC Update Manager"
  • Double-click it
  • PowerShell terminal window opens automatically


STEP 2: Wait for Application to Start
────────────────────────────────────────────────────────────────────────────
  • Terminal builds the application
  • Shows progress messages
  • When you see this, the app is ready:
    "Now listening on: http://localhost:5034"

  • Don't close this terminal! Leave it open.


STEP 3: Open Your Web Browser
────────────────────────────────────────────────────────────────────────────
  • Open Chrome, Edge, or Firefox
  • Click in the address bar
  • Type or paste: http://localhost:5034/file-updates
  • Press Enter


STEP 4: See Your Professional Interface! ✨
────────────────────────────────────────────────────────────────────────────
  • Beautiful gradient header appears
  • Statistics dashboard loads
  • Four professional tabs ready
  • Smooth animations throughout
  • Professional data displays


STEP 5: Start Using It!
────────────────────────────────────────────────────────────────────────────
  • Click "Sync Files" to add files from hosts
  • Click "Repository" to browse tracked files
  • Click "Distribute" to check for updates
  • Click "Report" to generate compliance report


STEP 6: When You're Done
────────────────────────────────────────────────────────────────────────────
  • Go back to the PowerShell terminal
  • Press Ctrl+C (hold Control, press C)
  • Application stops gracefully
  • Terminal closes (or type "exit")

🆘 QUICK HELP

CAN'T FIND THE SHORTCUT?
  → Check your desktop
  → Look in: C:\Users\634647\OneDrive - TMNA\Desktop\
  → Right-click desktop → Properties → Refresh

APP WON'T START?
  → Check PowerShell output for errors
  → Make sure you have .NET 10 SDK
  → Try running manually: dotnet run

BROWSER CAN'T REACH APP?
  → Wait 30 seconds for app to start
  → Check terminal says "Now listening on"
  → Try http://localhost:5034/ (without /file-updates)

PORT ALREADY IN USE?
  → Another app is using port 5034
  → Close other apps or wait for them to exit
  → Or change port in launchSettings.json
