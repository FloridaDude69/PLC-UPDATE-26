🔍 TECHNICAL EXPLANATION

The Warning:
  "Failed to determine the https port for redirect"

Why It Happened:
  1. Program.cs was calling `app.UseHttpsRedirection()`
  2. This middleware tries to redirect HTTP → HTTPS
  3. In development with HTTP-only, no HTTPS port was configured
  4. Middleware warned about missing HTTPS port

The Fix:
  Moved `UseHttpsRedirection()` inside the production check:

  ```csharp
  if (!app.Environment.IsDevelopment())
  {
      // Only run in production
      app.UseHttpsRedirection();
  }
  ```

Result:
  ✅ Development uses HTTP directly (no redirect attempt)
  ✅ Production redirects HTTP → HTTPS (secure)
  ✅ No warnings in development
  ✅ Best practices followed
