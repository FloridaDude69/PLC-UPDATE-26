📋 STEP-BY-STEP: FIND YOUR IP ADDRESS

If you need to find your IP address manually:

METHOD 1 - From the Batch File:
    The batch file displays your IP automatically when you run it.

METHOD 2 - Command Prompt:
    1. Press Windows + R
    2. Type: cmd
    3. Press Enter
    4. Type: ipconfig
    5. Look for "IPv4 Address" under your network adapter
       Example: IPv4 Address. . . . . . . . . . . : 10.0.1.45

METHOD 3 - Settings:
    1. Open Windows Settings
    2. Go to: Network & Internet
    3. Click on your connection (WiFi or Ethernet)
    4. Scroll down to see your IPv4 address

⚠️ IMPORTANT: WINDOWS FIREWALL

The first time you run network mode, Windows Firewall may prompt you:

    "Windows Defender Firewall has blocked some features of this app"

Click "Allow access" to enable network connections.

If the prompt doesn't appear but connections don't work:

OPTION 1 - Allow through Firewall (recommended):
    1. Open Windows Defender Firewall
    2. Click "Allow an app or feature through Windows Defender Firewall"
    3. Click "Change settings"
    4. Click "Allow another app..."
    5. Browse to: C:\Program Files\dotnet\dotnet.exe
    6. Check both "Private" and "Public" boxes
    7. Click OK

OPTION 2 - Create Firewall Rule manually:
    Run this PowerShell command as Administrator:

    New-NetFirewallRule -DisplayName "PLC Update Manager" -Direction Inbound -Protocol TCP -LocalPort 5034 -Action Allow

🔍 TROUBLESHOOTING

ISSUE: Other computer can't connect
SOLUTIONS:
    ✓ Make sure both computers are on the same network
    ✓ Check Windows Firewall settings (see above)
    ✓ Verify you're using the correct IP address
    ✓ Make sure the application is running
    ✓ Try disabling VPN if connected

ISSUE: "Connection refused" error
SOLUTIONS:
    ✓ Make sure the application is started
    ✓ Wait a few more seconds for startup
    ✓ Check the command window for errors
    ✓ Verify port 5034 is not blocked

ISSUE: "This site can't be reached" 
SOLUTIONS:
    ✓ Double-check the IP address
    ✓ Make sure you typed :5034 (with the port)
    ✓ Try http:// not https://
    ✓ Check if computers are on same network

ISSUE: Firewall keeps blocking
SOLUTIONS:
    ✓ Run the firewall rule command above
    ✓ Temporarily disable firewall to test
    ✓ Check corporate network policies
