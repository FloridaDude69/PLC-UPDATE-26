🆘 TROUBLESHOOTING

Problem: Shortcut doesn't appear on desktop
Solution: Check C:\Users\634647\OneDrive - TMNA\Desktop\ in File Explorer

Problem: Double-clicking doesn't work
Solution: Right-click shortcut → Select "Open" → Or try different method

Problem: PowerShell window closes immediately
Solution: Check the terminal output for error messages
        Solution: Try running from command line to see the error

Problem: "Now listening on" message doesn't appear
Solution: Wait a few seconds for application to build and start
        Solution: Check if port 5034 is already in use

Problem: Browser can't reach http://localhost:5034
Solution: Make sure the PowerShell terminal is still open
        Solution: Check that the terminal shows the listening message
        Solution: Try http://localhost:5034/file-updates (note the /file-updates)
