📖 STEP-BY-STEP WALKTHROUGH

STEP 1: Click the Shortcut on Desktop
─────────────────────────────────────────────────────────────────────────────
  Action: Double-click "PLC Update Manager" on your desktop
  Result: PowerShell terminal window opens

STEP 2: Wait for Application to Start
─────────────────────────────────────────────────────────────────────────────
  Wait for: "Now listening on: http://localhost:5034"
  Time:     Takes about 10-30 seconds
  Note:     Keep terminal open, do NOT close it!

STEP 3: Open Web Browser
─────────────────────────────────────────────────────────────────────────────
  Browser:  Chrome, Edge, or Firefox
  URL:      http://localhost:5034/file-updates
  Action:   Type URL and press Enter

STEP 4: Professional Interface Loads!
─────────────────────────────────────────────────────────────────────────────
  See:      Beautiful gradient header
  See:      Statistics dashboard
  See:      Modern tab interface
  See:      Professional styling throughout

STEP 5: Start Testing Features
─────────────────────────────────────────────────────────────────────────────
  Click "Sync Files" - Add test files
  Click "Repository" - View tracked files
  Click "Distribute" - Check for updates
  Click "Report" - Generate compliance report

STEP 6: Stop When Done
─────────────────────────────────────────────────────────────────────────────
  Action:   Press Ctrl+C in the PowerShell terminal
  Result:   Application stops gracefully
  Optional: Type "exit" to close the terminal
