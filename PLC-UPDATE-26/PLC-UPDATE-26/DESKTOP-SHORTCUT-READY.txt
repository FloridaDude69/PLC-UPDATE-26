🔧 WHAT THE SHORTCUT DOES

Behind the Scenes:

  1. Windows reads the shortcut file
  2. Launches the batch file: PLC Update Manager.bat
  3. Batch file changes to project directory
  4. Executes: dotnet run --no-launch-browser
  5. Application starts on port 5034
  6. Batch file waits 4 seconds
  7. Opens browser to: http://localhost:5034/file-updates
  8. Your interface displays
  9. Ready to use!

All automatic - you just click once!
