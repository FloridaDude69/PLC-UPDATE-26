## ⏹️ When You're Done

### To Stop the Application

1. Go to the PowerShell terminal window

3. Terminal will show shutdown message
4. Application stops

## 🆘 Quick Troubleshooting

| Problem | Solution |
|---------|----------|
| Shortcut not on desktop | Check: C:\Users\634647\OneDrive - TMNA\Desktop\ |
| Double-click does nothing | Right-click → Open, or try again |
| PowerShell closes immediately | Error in build - check terminal output |
| Browser can't reach the app | Ensure PowerShell shows "Now listening on..." |
| Port 5034 in use | Run `netstat -ano \| findstr :5034` |
| Want to stop app | Press Ctrl+C in PowerShell terminal |
