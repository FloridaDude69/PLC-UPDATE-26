📐 HOW IT WORKS (Simple Explanation)

CSS clamp() = "Be between X and Y, but scale with screen size"

Example: font-size: clamp(12px, 2vw, 18px)
  • Phone (375px):    Uses 12px (minimum)
  • Tablet (768px):   ~15px (2% of 768)
  • Desktop (1920px): Uses 18px (maximum)
  • Scales smoothly between!
