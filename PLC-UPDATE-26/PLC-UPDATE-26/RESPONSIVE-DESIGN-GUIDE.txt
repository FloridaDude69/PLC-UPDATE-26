📐 HOW RESPONSIVENESS WORKS

CSS clamp() Function:
  Syntax: clamp(MIN, PREFERRED, MAX)

  Example: font-size: clamp(12px, 2vw, 18px)
  • Minimum: 12px
  • Preferred: 2% of viewport width
  • Maximum: 18px

  This means:
  • On small screens: uses 12px minimum
  • On medium screens: grows with viewport
  • On large screens: caps at 18px
  • Always readable and scalable!

Benefits:
  ✓ No fixed sizes
  ✓ Smoothly scales
  ✓ No jarring breakpoints
  ✓ Perfect on any size

📊 RESPONSIVE FEATURES

Flexible Grid:
  .display-cards {
    grid-template-columns: repeat(auto-fit, minmax(clamp(...), 1fr));
  }

  This means:
  • Automatically fits as many cards as fit
  • Minimum width adapts to screen
  • Perfect layout on any size

Fluid Typography:
  .header-title {
    font-size: clamp(28px, 6vw, 48px);
  }

  • Small phones: 28px
  • Medium devices: scales with viewport
  • Large desktops: 48px
  • Always proportional!

Adaptive Spacing:
  .sidebar {
    padding: clamp(15px, 3vw, 30px);
  }

  • Phone: 15px padding
  • Proportional scaling
  • Desktop: 30px padding
  • No wasted space!
