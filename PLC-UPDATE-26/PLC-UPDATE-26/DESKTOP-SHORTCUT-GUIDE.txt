💡 TIPS FOR USING THE SHORTCUT

✓ MINIMIZING THE COMMAND WINDOW
  The command window stays open while the app runs.
  You can minimize it to the taskbar.
  The application continues running in the background.

✓ STOPPING THE APPLICATION
  Close the command window to stop the application.
  This will also close your browser connection.

✓ USING WHILE MINIMIZED
  You can minimize the command window.
  Keep using the application normally.
  The window doesn't need to be visible.

✓ MULTIPLE INSTANCES
  You can only run one instance at a time.
  Close the previous one before running again.

✓ PORT ALREADY IN USE
  If port 5034 is in use, you'll get an error.
  Close any other instances of the application.

🔍 IF SOMETHING DOESN'T WORK

Issue: Browser doesn't open automatically
  → Wait 10 seconds, then manually open: http://localhost:5034/file-updates
  → Check that the command window is still open

Issue: Port 5034 already in use
  → Another instance is running
  → Close any command windows running the app
  → Wait 5 seconds, then try again

Issue: Application won't start
  → Check internet connection
  → Make sure no firewall is blocking port 5034
  → Try running from Visual Studio first

Issue: Command window closes immediately
  → Check the error messages
  → Ensure .NET 10 SDK is installed
  → Run "dotnet --version" in PowerShell to verify
